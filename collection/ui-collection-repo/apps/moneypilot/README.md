# MoneyPilot

Personal finance planner: budgets, goals and subscriptions. All data is simulated demo data.

## Run locally
Open index.html in a browser (extract the zip first).

## Stack
HTML5, CSS3, vanilla JavaScript, inline SVG charts, localStorage. No dependencies.

## Features
Search, filter, edit, add and delete interactions; a local AI assistant that answers from the app's own data (Reason, Evidence, Recommendation, Confidence); light/dark theme; responsive layout; keyboard and screen-reader support.
